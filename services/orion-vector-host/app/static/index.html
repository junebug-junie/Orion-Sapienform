WHAT THIS ACTUALLY IS

This panel polls GET /api/self-brain/frames/tail (orion-hub, backed by SubstrateBrainFrameV1 in orion-substrate-runtime, persisted every 5s) and displays three independently-sourced, independently-verified real signals -- not a fused "consciousness meter."
